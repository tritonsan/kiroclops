Flow
1The reference clip is measured once with OpenCV 5.
2The agent calls KiroClops through eight MCP tools.
3The agent edits only the target's motion code.
4Every candidate is re-recorded in Chromium or Godot.
5OpenCV 5 tracks objects, finds events, compares windows.
6Feedback returns to the agent; held-out cases stay sealed.
7Optional: the same request goes to the AWS API.
8Lambda stores the job and queues it.
9A Graviton4 COOL worker measures it and signs a receipt.
